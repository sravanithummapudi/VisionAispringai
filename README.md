## Vision Ai
## Overview  
This project is a full-stack web application that generates recipes and images using AI. It is built with:  
- **React.js** (Frontend)  
- **Spring Boot** (Backend)  
- **Spring AI** (AI Integration)  

## Features  
- Generate recipes based on user input.  
- Generate  images using OpenAI's image model.  
- Interactive and user-friendly UI with React.  
- Backend powered by Spring Boot and Spring AI.
